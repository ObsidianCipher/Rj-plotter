
# rj

A small React + TypeScript starter built with TanStack and Tailwind CSS.

## Built with

- TanStack Start
- TypeScript
- React
- Tailwind CSS

## Getting Started

1. Install dependencies

```bash
npm install
```

2. Run the development server

```bash
npm run dev
```

## Project structure

- src/ — application source code
- public/ — static assets
